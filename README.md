# Task-4-CRUD-Operation-using-PostmanAPI

# 🌟 Basic REST API with Node.js and Express 🚀  

This project is a simple REST API built using **Node.js** and **Express.js** for performing CRUD operations on a "User" entity. It demonstrates the fundamentals of REST API design and backend development.  

## ✨ Features  
- 🔍 **Retrieve All Users**: Fetch all users in the database.  
- 🆔 **Get User by ID**: Fetch a single user's details using their ID.  
- ➕ **Create a New User**: Add a new user with `name`, `email`, and `age` fields.  
- ✏️ **Update an Existing User**: Modify an existing user's details.  
- ❌ **Delete a User**: Remove a user from the database.  

## 🛠️ Technologies Used  
- ⚡ **Node.js**  
- 🌐 **Express.js**  
- 🧪 **Postman** (for API testing)  

## 🌐 API Endpoints  
| 🔧 Method | 🌍 Endpoint       | 📋 Description                 |  
|-----------|-------------------|---------------------------------|  
| GET       | `/users`          | Retrieve all users.             |  
| GET       | `/users/:id`      | Retrieve a user by ID.          |  
| POST      | `/users`          | Add a new user.                 |  
| PUT       | `/users/:id`      | Update a user's information.    |  
| DELETE    | `/users/:id`      | Delete a user.                  |
